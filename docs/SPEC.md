# Разбор шахматных партий — описание

Приложение для глубокого разбора своей сыгранной партии. Партия попадает в
него с бланка: набором ходов, вставкой текста, а позже фотографией. Движок
Stockfish проходит каждый ход и показывает, где игра была точной, где
ошиблись, что было лучше и чем наказывается сыгранное.

Пользователь — взрослый шахматист, играет турниры в Германии, бланки
заполнены немецкой нотацией (K, D, T, L, S).

## Чем отличается от того, что уже есть

Разбор партий есть у chess.com (Game Review, платно) и у lichess (бесплатно,
но без объяснений). Распознавание бланков по фото есть у мобильных
приложений ChessScan, Chess2PGN, Score Sheet Scanner и Chess PGN Scanner. Все
англоязычные и все с подпиской.

Наши отличия:

1. **Распознавание с проверкой правилами.** Модель читает каждый ход с
   несколькими вариантами прочтения, и остаётся только тот, что допустим в
   позиции. Сомнительные клетки бланка показываются рядом с доской на
   подтверждение одним нажатием. *(шаг 2)*
2. **Любая нотация на входе** — немецкая, английская, русская, короткая и
   длинная, без настройки. *(сделано)*
3. **Движок считает, модель только пересказывает.** Оценки и варианты — от
   Stockfish, объяснения — пересказ этих фактов. *(шаблоны сделаны, живой
   пересказ — шаг 3)*
4. **Глубина разбора**: точность по сторонам и по стадиям партии, классы
   ходов, переломные моменты, график. *(сделано)*
5. **Тренировка на своих ошибках**: позиции, где был зевок, становятся
   задачами. *(шаг 4)*
6. **Без сервера и без подписки**: статические файлы на GitHub Pages,
   работает офлайн, ставится на телефон.

## Что есть сейчас (0.1)

### Архив

- Список партий от последних изменённых, с игроками, датой, турниром,
  результатом и точностью сторон, если партия разобрана.
- Партии хранятся на устройстве (localStorage, Р-6).

### Ввод

- Ход текстом в поле: понимается любая нотация (Р-3). На невозможный ход
  приходит понятный отказ, набранное не стирается.
- Ход нажатием по доске: фигура → подсказка, куда можно пойти → поле.
  Выбор фигуры при превращении.
- Вставка текста партии: PGN или запись с номерами. На первом непонятом
  ходе разбор останавливается и называет его («ход 14 чёрных «Lxe5»:
  невозможен»), уже понятые ходы сохраняются.
- Заголовки: игроки, турнир, дата, результат (при мате и пате ставится
  сам).
- Отмена хода, переворот доски, копирование PGN, удаление партии.

### Разбор

- Движок проходит партию сам при открытии, экран показывает готовое по мере
  счёта. Готовые оценки сохраняются, прерванный разбор продолжается с места
  остановки.
- Доска со знаком класса хода на поле, стрелкой лучшего хода, шкалой
  оценки.
- Карточка хода: класс, оценка, точность хода, объяснение, лучшее
  продолжение и чем наказывается сыгранный ход — оба можно проиграть на
  доске.
- График шансов по ходам с отметками ошибок; нажатие переходит к ходу.
- Сводка: точность по lichess, средняя потеря, счёт классов, точность по
  стадиям.
- Переломные моменты — до трёх самых дорогих ходов.
- Листание стрелками клавиатуры, кнопками, по списку ходов.

### Классы ходов

| Класс | Условие |
|---|---|
| Единственный | Лучший ход, второй по силе хуже на 20%+ шансов и оставляет меньше 50% |
| Лучший | Совпал с первым ходом движка |
| Отличный | Потеря меньше 2% шансов |
| Хороший | Меньше 5% |
| Неточность | Меньше 10% |
| Ошибка | Меньше 20% |
| Зевок | 20% и больше |
| Вынужденный | Другого хода не было; в точность не идёт |

### Настройки

- Нотация показа: немецкая (по умолчанию), английская, русская.
- Глубина движка: 10 / 14 / 18.

## Дальше

**Шаг 2 — фото бланка.** Снимок → Gemini по личному ключу, как в трекере
тренировок → по каждому ходу несколько вариантов прочтения → сверка с
допустимыми ходами → неуверенные места на подтверждение с вырезкой клетки
бланка. Поддержка двух страниц бланка.

**Шаг 3 — живые объяснения.** Gemini пересказывает факты движка понятным
языком: какая угроза, какой план, почему ход плох. Факты только от движка.

**Шаг 4 — тренировка.** Зевки из архива становятся задачами «найди ход».

**Шаг 5 — дебюты и рост.** Название дебюта по базе lichess (CC0), момент
выхода из теории; динамика точности по партиям; примерный уровень игры в
партии.
