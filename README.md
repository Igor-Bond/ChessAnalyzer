# Разбор партий

Живой адрес: https://igor-bond.github.io/ChessAnalyzer/

Разбор своей шахматной партии движком Stockfish прямо в браузере. Ходы
вводятся с бланка — немецкой, английской или русской записью, — и движок
проходит каждый: где игра была точной, где ошибка, что было лучше и чем
наказывается сыгранное. Работает офлайн, ставится на телефон как приложение.

Полное описание — [docs/SPEC.md](docs/SPEC.md).
Что и почему решали — [docs/DECISIONS.md](docs/DECISIONS.md).

## Состояние

Версия 0.7: задачи с уровнями — с lichess по рейтингу и теме (с запасом на
время без сети) и из своих ошибок с повторением по интервалам; свободная
доска — доигрыш движком с любой позиции и расстановка фигур; «Детально» по
игроку партии; правка любого записанного хода; обмен партиями между
устройствами (вход Google, как в трекере); фото бланка через Gemini со
сверкой по правилам шахмат; ввод ходов (текстом, по доске, вставкой PGN);
разбор с классами ходов, точностью по lichess, стадиями партии, графиком,
переломными моментами и просмотром вариантов.

Дальше: живые объяснения, дебюты.

## Запуск

Сборка не нужна, но модули ES и сервис-воркер не работают через `file://`:

```bash
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
```

Затем открыть `http://localhost:4190` (только `localhost`, не `127.0.0.1`).

## Проверки

Открыть `http://localhost:4190/tests/index.html`. Итог — в заголовке
вкладки и в `globalThis.__RESULT__`. Проверки гоняют настоящий Stockfish,
полный прогон — около минуты. В CI их запускает
[tools/ci-tests.mjs](tools/ci-tests.mjs) на каждый push.
